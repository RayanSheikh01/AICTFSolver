# AI CTF Solver

Autonomous LangGraph agent that solves Web/Recon CTF challenges in a sandboxed Docker container and emits a publishable write-up.

See [design.md](design.md) for the rationale and [imp_plan.md](imp_plan.md) for the implementation plan.

## Install

```
pip install -e ".[dev]"
```

## Test

```
pytest -v
```
